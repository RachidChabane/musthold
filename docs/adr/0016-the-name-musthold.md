# ADR 0016: The name Musthold

Status: accepted. Supersedes the "Name" decision of ADR 0015. Every other decision
of ADR 0015 stands.

## Context

ADR 0015 kept the working name `spec-proof`. The name is free on every registry.
It is also generic: it describes a category rather than a product, and a
neighbouring project already publishes as "spec-to-proof". A launch whose aim is to
be noticed needs a name that is distinctive and that people can say aloud.

The product works beside Shallnot, whose name is the RFC 2119 keyword SHALL NOT.
Shallnot proves that each requirement is traced to its tests. This product proves
that those tests discriminate: the requirement must hold, and a change that breaks
it cannot pass.

Before publication, the name is cheap to change. After the first module tag, the
Go module proxy keeps the module path forever.

## Decision

- **The product is named Musthold.** It takes the RFC 2119 keyword MUST and the
  property every requirement is proven to have: it holds. The pair reads as one
  family: Shallnot traces, Musthold proves.
- **Checked free:** no GitHub repository named `musthold`, no PyPI, npm or Homebrew
  package, and no software product under that name. `musthold.dev` and
  `musthold.io` have no DNS delegation. `musthold.com` is parked for sale.
- **What changes before publication:**
  - the repository becomes `github.com/RachidChabane/musthold`;
  - the module paths become `github.com/RachidChabane/musthold/<module>`;
  - the binaries change their prefix from `spec-proof-` to `musthold-`;
  - the plugin and marketplace names, the umbrella skill (`musthold:prove-all`),
    the configuration directory and the cache directory (`.musthold/`), and the
    environment variables (`MUSTHOLD_`) change to match;
  - the module names that statements carry as `module.name`, such as
    `musthold-alignment`. The format's reference vectors hold these names as data,
    so they are regenerated, and Shallnot's copies of them are resynced;
  - the docs and the README change to the new name.
- **What does not change:**
  - The predicate and schema URIs under `https://rachid-chabane.com/`. They carry
    no product name.
  - The four frozen studies, `experiments/calibration`, `experiments/demos-1`,
    `experiments/limits-1-3` and `experiments/validity-w`, stay byte-identical,
    with their tags and recorded runs. Each builds the product from its own tagged
    commit, so the rename does not reach what they run. They name `spec-proof` as
    the product they ran, which stays true of their history.
- **Shallnot.** Shallnot names the product in its default verified directory, in
  the binary each proof finding points to, in the umbrella skill and in its docs.
  These take the new names in the same step, and Shallnot v0.5.0 is released with
  them. The pin moves to that release.
- **Mechanics.** The rename is one script that can be run again. It maps every case
  form of the old name, longest first, and moves the paths that carry it. Derived
  files are regenerated by their own generators, never edited by hand. A residue
  check fails on any remaining occurrence outside an explicit allowlist.
- **Order.**
  - The rename lands on `main` after the launch branches are integrated, in one
    change with no alias for the old name.
  - It lands before the launch demo is recorded, so the recording shows the
    published names.
  - It lands before `loop-1` is frozen, so its protocol names the published binaries.
  - It lands before the public repository is built, so the public history never
    publishes a tag under the old module path.

## Consequences

- The archive repository keeps the old name in its history. ADR 0015's history
  filter needs no new rule for the name.
- The frozen studies keep the old binary names and paths in the public tree. A
  reader replicating one checks out its tag, where those names are the ones built.
- Users of the unpublished `spec-proof` paths: there are none outside this
  repository, so no compatibility shim is kept.
- The name is not registered as a trademark. If a conflict appears before launch,
  it is handled here, by a new ADR.
