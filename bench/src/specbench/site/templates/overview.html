Do proofs catch what green tests miss?

A coding agent says it is done and its tests pass. musthold checks that those tests verify what the specification requires: it runs them against mutants that violate a criterion, judges whether each test checks its criterion, and blocks the change when they do not. This site reports what that gate did on the tasks of one run, beside the same changes accepted by tests alone.
